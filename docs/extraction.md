# 代码提炼说明

本目录是原项目的独立源码副本；原项目的代码、数据和论文文件未被迁移或删除。

保留了构图、固定划分、四种 KGE 基线、ULTRA 适配、KG-ICL 推理、统一评价、药材和基础方发现、队列统计、策略比较以及绘图源码。输入输出目录通过空 `.gitkeep` 保留，所有数据表、记录、权重、结果、图像和论文附件均未复制。

在副本中做了以下整理：

- `src/kg_construct.py` 的 Windows 反斜杠输出目录改为跨平台 `Path` 拼接，仍指向 `outputs/knowledge_graph/`。
- `05_export_ultra_results.py` 提炼为 ULTRA 模型加载、词表重建和评分函数；删除历史报表生成入口。
- `09_consolidate_model_comparison.py` 提炼为主比较和独立重复共用的指标计算函数；删除旧词表和历史模型重载入口。
- `07_train_ultra_targeted.py` 保存已经计算出的零样本分数，衔接 `11_finalize_primary_comparison.py` 原本要求的同名输入，不改变分数或模型选择计算。
- 去掉绘图/验证代码中直接写入的研究观察总量，改为从本地输入计算或做结构检查；保留方法参数、类别键及固定研究协议检查。
- 文档中的个人 Python 绝对路径改为 `python`；删除已不存在的历史绘图命令；绘图来源哈希指向本目录现有 README。

没有纳入旧 ConvE 训练/导出入口、依赖缺失配置的 `06_run_ultra_all.py`、旧独立汇总程序、论文写作/审稿/LaTeX 工具，以及与方法无关的编辑器和技能文件。

第三方源码及原始许可证保留在 `external/`。没有嵌套 Git 历史、Git 子模块或指向原项目的符号链接。

本次核验覆盖源码语法、数据文件排除、内部引用及内存算法测试；未使用原始研究数据重新训练或宣称复现论文指标。
